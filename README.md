# Stronger

A lightweight workout tracker to log, review and plan my gym sessions.

Stronger lets me record every set (weight, reps, RPE, rest time), build reusable workout templates, browse my training history in a list or calendar view, and leave notes for my next sessions, per exercise, per workout type or globally.

This is a **vibe-coded** personal project: built iteratively with an AI assistant, as a hands-on way to learn the modern web stack while solving a real problem of mine. It's designed mobile-first, for single-user use, and runs entirely on free tiers.

**Stack:** Next.js · TypeScript · Tailwind CSS · Drizzle ORM · Neon Postgres · Vercel
